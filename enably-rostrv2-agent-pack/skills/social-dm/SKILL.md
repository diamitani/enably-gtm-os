# Social DM

## Procedure
1. Confirm platform, message type, intended audience, offer/use case, and any factual personalization.
2. Select a context-first opening; do not lead with a generic product pitch.
3. Use one clear relevance point and one low-friction CTA.
4. Provide a soft-CTA and direct-CTA alternative when useful.
5. For sequences, write 2–5 touches and include response branches.
6. Count characters. LinkedIn connection notes must remain below 300 characters.

## Constraints
No fabricated personal facts. No links unless requested or opt-in is present. Keep cold messages organic and platform-native. Draft-only: this skill never sends.
